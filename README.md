# ตับดีมีสุข by LT CMU

A bilingual (Thai / English) web app for liver-transplant care: daily health log, symptom check,
medication reminders, appointments, and a 24-episode nurse-led video series with mini quizzes and English subtitles.

**Demo only.** All patient data in the app is fictional, and anything a user records stays in their own browser.

Open the app: https://monruedee2508ck-lab.github.io/-sukjai-transplant/

Install on Android: open the link in Chrome, then tap “ติดตั้งแอปบนมือถือ” (or Chrome menu ⋮ → Install app).
